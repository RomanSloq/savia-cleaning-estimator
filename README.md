# Savia

Независимый портфолио-проект: одностраничный сайт вымышленного клинингового бренда Savia в Перми.

## Текущий этап

Stage 3: интерактивный калькулятор подключён к изолированной демонстрационной ценовой логике. Отправка формы, интеграции и публикация отсутствуют.

## Источники истины

- [`AGENTS.md`](AGENTS.md) — обязательные правила для дальнейшей работы.
- [`docs/PRODUCT.md`](docs/PRODUCT.md) — цель, аудитории, scope, ограничения и критерии успеха.
- [`docs/DESIGN.md`](docs/DESIGN.md) — визуальное направление, адаптивность, доступность и правила работы с фотографиями.
- [`docs/CONTENT.md`](docs/CONTENT.md) — рабочие тексты и ограничения на неподтверждённые утверждения.

Savia — вымышленный бренд. Факты, относившиеся к исходному бизнесу, не переносятся как утверждения о Savia.

## Рабочий процесс

1. Перед существенной работой прочитать `AGENTS.md`, этот файл и все документы в `docs/`.
2. Согласовать небольшой этап и перечислить файлы, которые планируется изменить.
3. Реализовать только согласованный scope.
4. Проверить релевантный пользовательский сценарий, адаптивность и доступность соразмерно этапу.
5. Обновить канонические документы, если изменились решения или фактическое состояние.
6. Показать изменения и результаты проверок. Commit и push выполнять только по явному разрешению.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проверки перед ревью:

```bash
pnpm check
pnpm build
pnpm test
```
