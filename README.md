# Savia — калькулятор стоимости клининга

Savia — адаптивный портфолио-проект клинингового сервиса: русскоязычный лендинг, детерминированный калькулятор стоимости и полный сценарий от расчёта до отправки заявки. Валидный расчёт передаётся в форму контактов, повторно проверяется на сервере и доставляется в Telegram.

## Что демонстрирует проект

- адаптивную реализацию лендинга для ПК, планшета и телефона
- Astro и TypeScript без тяжёлого UI-фреймворка
- собственный CSS и доступные нативные элементы управления
- детерминированный калькулятор с понятными состояниями валидации
- передачу состояния из калькулятора в форму
- клиентскую и серверную валидацию заявок
- повторный расчёт стоимости на сервере перед отправкой
- доставку заявок в Telegram через серверный адаптер
- автоматические тесты для расчётов, данных заявки, валидации, API-маршрута и Telegram-доставки
- хранение секретов вне клиентского кода

## Продуктовое решение

В основе проекта — бриф реального локального клинингового бизнеса. В первоначальный план входил калькулятор стоимости, однако в ходе уточнения требований выяснилось, что реальные заказы рассчитываются индивидуально: объём зависит от конкретного объекта и задачи.

Поэтому были выбраны два направления. В реальном бизнес-сценарии оставлена заявка на индивидуальный расчёт — без калькулятора, который мог бы создать ложное ожидание точной цены. В отдельной портфолио-версии детерминированный калькулятор добавлен намеренно: он показывает логику интерфейса, валидацию и полный сценарий заявки, не выдавая демонстрационную стоимость за коммерческое обещание.

## Ключевые возможности

- обзор услуг, описание процесса, галерея, калькулятор и форма заявки на одной адаптивной странице
- параметры калькулятора: тип объекта, вид уборки, площадь, регулярность и дополнительные услуги
- состояния пустого, корректного и некорректного ввода с форматированием цены для русского языка
- передача актуального расчёта в форму и очистка устаревшего расчёта при невалидном исходном значении
- обязательные имя и контакт, необязательный комментарий, видимая валидация, статусы отправки и honeypot-поле
- ограниченная обработка JSON-запроса и серверная валидация
- отдельные состояния успешной отправки, отсутствующей конфигурации и ошибки доставки

## Архитектура

```text
Калькулятор
  → Форма заявки
  → POST /api/lead
  → Серверная валидация
  → calculatePrice()
  → Telegram-адаптер
  → Telegram Bot API
```

Браузер может передать расчёт как контекст заявки, но сервер не доверяет присланной цене. Он проверяет данные и повторно вызывает `calculatePrice()` перед формированием сообщения в Telegram. `LeadPayload` не зависит от транспорта доставки, а Telegram-специфичная логика остаётся в серверных модулях.

## Тестирование

В репозитории сейчас **45 автоматических тестов в 5 файлах**. Они покрывают границы и округление цены, формирование данных заявки, серверную валидацию и повторный расчёт, ответы API-маршрута и форматирование/доставку Telegram-сообщений.

Интерфейс также проверен на ПК, планшете и телефоне: проверены крайние состояния калькулятора, состояния формы, клавиатурное управление и базовая доступность интерактивных элементов.

## Локальная разработка

```bash
pnpm install
pnpm dev
```

Полезные проверки:

```bash
pnpm test
pnpm check
pnpm build
```

Чтобы включить локальную доставку в Telegram, создайте локальный `.env` на основе `.env.example` и задайте серверные переменные:

```text
TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
```

Не помещайте эти значения в клиентский код и не коммитьте их в репозиторий.

## Деплой

Лендинг предварительно генерируется как статический вывод. Маршрут `/api/lead` выполняется по запросу на сервере и собирается через адаптер Vercel. Предполагаемая платформа деплоя — Vercel; секреты Telegram должны храниться в переменных окружения.

Публичная ссылка будет добавлена после деплоя на Vercel.

## Примечание о демо

Savia — портфолио-проект. Правила расчёта и изображения имеют демонстрационный характер; проект не заявляет о выполненных заказах реальной компании Savia.
